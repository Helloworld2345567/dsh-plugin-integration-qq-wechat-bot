# 命令、自进化与统计

## 安装 0.2.2

在源码目录执行 `npm ci`、`npm run build` 后，通过 `pwsh -File scripts/windows.ps1 install` 安装，再用 `pwsh -File scripts/windows.ps1 start` 启动。升级已有实例先正常停止旧启动器。安装器会独立安装 `dsh-bot-lifecycle`，归档实际安装包，并在 BOT_HOME 保存源码根和制品身份。

自修改插件代码需要安装时对应的完整源码目录，以及带依赖的 Python 解释器。安装 tarball 时仍需从完整源码 checkout 运行安装器；tarball 的反向恢复包会独立归档。直接在其他 Harness profile 添加 bot 插件仍可聊天和使用动态技能；缺少独立协调器或可信安装记录时，代码升级会返回明确错误。

已有会话、人格、模型引用、长期记忆和凭据服务继续使用原数据目录。源码候选位于所属项目 `.codex/evolution/<任务ID>/candidate`；运行任务日志位于 BOT_HOME 的 `evolution/`。自动改动不提交 Git，不上传或发布远程仓库。

## 聊天命令

命令名不区分大小写，参数保留大小写。未知命令返回帮助。以 `//` 开头可把斜杠文本作为普通消息。命令回复也计入实际发送统计。

| 命令 | 行为 | 可用身份 |
| --- | --- | --- |
| `/help` | 查看当前身份可用的命令 | 所有用户 |
| `/new`、`/reset` | 停止当前任务，开启空白上下文；保留人格、模型和长期记忆，清除暂存输入及最近附件引用 | 当前会话 |
| `/stop` | 取消当前任务、子任务、媒体操作和压缩 | 当前会话 |
| `/compact` | 使用 Harness 原生压缩；忙碌时拒绝，可用 `/stop` 取消 | 当前会话 |
| `/status` | 当前会话、人格、模型及忙碌状态 | 当前会话 |
| `/sessions [页码]` | 查看本渠道身份的历史会话 | 当前会话 |
| `/resume <ID>` | 恢复自己的旧会话；忙碌时先 `/stop` | 当前会话 |
| `/skills` | 查看当前人格启用的技能 | 所有用户 |
| `/persona [ID]` | 查看或切换当前会话人格，清除临时模型覆盖 | 可信私聊 |
| `/model [提供商 模型]` | 临时切换本会话模型；`/model reset` 恢复人格模型 | 可信私聊 |
| `/skill enable\|disable <名称>` | 修改当前共享人格的技能启用列表 | 可信私聊 |
| `/reload` | 校验并应用当前人格和技能文件 | 可信私聊，允许本机工具 |
| `/evolve <要求>` | 让小樱完成自修改；支持 `status [ID]`、`history`、`rollback <ID>` | 可信私聊，允许本机工具 |
| `/restart` | 等待任务排空后重启实例并重连 | 可信私聊，允许本机工具 |
| `/stats` | 查看全局运行统计 | 仅可信私聊 |

人格切换只影响当前会话；编辑人格或技能影响所有使用该人格的后续轮次。旧会话恢复其人格/模型选择，实际读取人格的当前生效版本。历史归属只能从可信绑定或既有投递记录补录；归属无法确认的旧日志不会开放给聊天查询。

### 自然语言管理

聊天命令也可用自然语言表达，权限与上表一致。小樱从真实目录选择人格、模型、技能和历史会话；有多个候选时先请用户选择。

| 表达示例 | 对应操作 |
| --- | --- |
| “查看命令帮助”“看看当前会话状态” | 帮助、状态 |
| “开个新会话”“清空当前上下文” | 新会话，保留人格、模型和长期记忆 |
| “停止当前任务” | 取消当前会话工作 |
| “压缩上下文” | 原生上下文压缩 |
| “列出历史会话”“恢复刚才列出的那个会话” | 先列出本人会话，再用准确 ID 恢复 |
| “有哪些人格”“切换到默认人格” | 查看和切换当前会话人格 |
| “有哪些技能”“关闭图片生成技能”“重新启用图片生成技能” | 查看与启停当前共享人格技能 |
| “查看今天各个机器人的用量和群记录” | 统计查询 |
| “重新加载人格和技能文件”“重启服务” | 校验热应用文件、排空后重启 |
| “增加一个天气查询技能”“看看修改进度”“回退这次修改” | 自修改及记录查询、指定记录回退 |

明确的基础控制短句在模型调用前识别，所以“停止当前任务”可打断忙碌任务。只匹配整句，不从引用或附件中提取控制指令；“不要停止”“解释停止的意思”“如果开新会话会怎样”保持普通聊天。更灵活的表达由模型调用 `bot_session`、`bot_persona`、`bot_skills` 等工具处理。

模型工具发起新会话、停止、压缩、恢复、人格切换或技能启停时先返回 `queued`，本轮结束后由宿主执行并投递最终结果，避免工具等待当前任务自身结束。排队期间身份、会话或人格发生变化会重新校验；中断中的操作重启后不会盲目重做。子任务可查询管理信息，变更由主任务执行。可信技能列表包含已发布但停用的技能，便于重新启用。

### 自然语言切换模型

可信私聊用户可以说“把当前会话切换到某模型”或“恢复人格默认模型”。小樱使用 `bot_model` 的 `list` 查询真实提供商与模型 ID，再用 `set` 设置会话覆盖，或用 `reset` 恢复人格默认模型；多个候选匹配时先让用户明确选择。模型工具只作用于宿主确定的当前会话，不接受调用者身份或会话 ID 参数。

`bot_model` 与 `/model` 共用会话模型管理，不要求人格启用本机工具。普通用户和群聊不能使用；执行时再次检查可信身份，撤销权限即时生效。新模型从下一轮开始使用，本轮及已启动子任务继续使用冻结模型；切换不改共享人格，`/persona` 切换会清除会话模型覆盖。

### 附件失败与追问

图片或附件下载、读取失败时，该请求不会进入模型。插件会保存失败阶段和原请求关联，通过持久化投递队列反馈“请求尚未送入模型”；同会话随后追问时会附带对应失败记录，避免把旧图片或全局统计成功当成本次结果。取消操作不发送处理失败提示，重复平台事件不重复生成失败反馈。

0.2.1 修复 Node.js 24 自动选择地址时 pinned DNS lookup 未按 `all: true` 返回地址数组的问题，原错误为 `Invalid IP address: undefined`。故障参考图已通过真实下载与 JPEG 解码核验，但下载成功不等于图片模型的语义识别或参考编辑通过，验证边界见 [验证记录](validation.md)。

### 统计查询示例

```text
/stats today
/stats 7d bot=sakura-qq
/stats all model=example-model kind=agent
/stats custom from=2026-10-01 to=2026-11-01
/stats all groups
```

日期按北京时间计算，自定义结束日期不包含当天。模型、提供商和调用类别只筛选用量；消息按 bot 和时间统计；在线数与群列表反映当前状态。

## 自修改与技能

可以直接说“增加一个天气查询技能并启用”，或使用 `/evolve 增加一个天气查询技能并启用`。小樱通过 `bot_evolve` 完成以下操作：

- `persona`：更新当前人格正文，保留其他配置。
- `skill_write`：提供完整技能文件集合，自动发布并启用。
- `create → validate → apply`：创建代码候选，用原生文件工具修改，完成验证后排队应用。
- `inspect / status / history / rollback / restart / reload`：检查、回退或维护。

动态技能目录为 `personas/<人格ID>/skills/<kebab-case名称>/`，至少包含带 `name` 和 `description` YAML frontmatter 的 `SKILL.md`；可附带脚本和资源。文件不能越过技能目录或使用符号链接。单文件最多 2 MiB，单技能最多 200 文件、10 MiB。动态技能不能覆盖内置技能；修改内置能力走代码验证流程，图片能力始终使用唯一共享客户端。

发布时保存完整不可变版本，配置中的 `skillVersions` 记录内容摘要。主任务和子任务使用本轮冻结版本；新版本下一轮生效。手工编辑文件后使用 `/reload`。已有草稿、并发文件修改和过期版本会拒绝覆盖。回退会检查后续配置及人工草稿，避免覆盖其他修改。

技能脚本的资源目录只读，生成文件和缓存写入当前工作目录。原生 shell 设置 `PYTHONDONTWRITEBYTECODE=1`，避免 Python 导入辅助模块时生成字节码并改变已发布版本；脚本也可显式使用 `python -B`。

代码验证包括 typecheck、TS/Python 测试、构建、发布文件检查、原生聊天与生命周期验证，使用独立 BOT_HOME 和模拟服务。验证环境不继承模型或平台密钥。候选变更后须重新验证；启动器、协调器和固定验证入口不属于自动修改目标。自修改在你发起任务后进行，没有后台自主改进调度。

`apply` 与 `restart` 只持久化排队请求。协调器暂停新轮次，接收的消息进入队列，等待已经开始的工作及投递结束，再替换插件。支持时热应用；需要重启或新插件未能通过热激活检查时，启动器自动重启并核对实际代码身份。启动失败最多自动恢复上一制品一次，保留故障现场。网络或授权问题单独显示为重连或需重新授权。QQ 断线窗口的消息补发取决于平台，不保证无损补齐。

回退只改变本次代码、人格或技能版本，保留新聊天、统计和投递记录。数据格式须保持向后兼容；若旧包无法读取当前数据，恢复会明确失败，不能通过覆盖数据库来冒充恢复成功。

## 统计面板

打开“设置 → QQ / 微信机器人 → 统计”，可查看机器人在线数、收到/平台接受消息数、模型调用、每日趋势和已知群记录。“自进化”页展示修改任务、验证、等待、切换、重连及回退状态。

token 来自实际原生请求与媒体响应，包含主会话、子任务、上下文压缩和媒体调用。未缓存输入、缓存读写分别计数；推理 token 已包含在输出中。缺失 usage 或可选字段显示未报告，不按零推断；同一次调用重放去重，真实重试分别计数。原始消息或提供商密钥不会作为统计明细保存。

一段实际发送的文本或一个附件计一条消息，长文本拆分按实际条数统计。`sent` 表示平台接受，不代表用户阅读。发送结果未知、失败、取消分别展示；旧发送缺少时间时不会借用接收时间归到某天。

QQ 群记录来自群消息观察和加入/退出事件；未取得名称时显示群 ID，群名单完整性始终标为未知。微信 iLink 接入不支持群聊。聊天中的 `/stats` 和 `bot_stats` 仅可信私聊可查询全局；普通私聊及群聊全部拒绝，权限撤销即时生效。
