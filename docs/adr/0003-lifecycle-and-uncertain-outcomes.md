# ADR 0003：生命周期独立，未知结果不自动重放

- 状态：已接受
- 日期：2026-11-03

## 背景

主机器人 bundle 是升级目标，不能可靠地负责卸载和替换自己。网络提交、远程推理或取消也可能进入无法确认成功或失败的状态；自动重放会造成重复推理或重复投递。

## 决策

1. 独立产品 profile 使用单独的 `dsh-bot-lifecycle` bundle 协调排空、安装、监督重启和一次回滚；该 bundle 不依赖可变的 `botIntegration` 服务。
2. 升级只接受通过 archive 安全验证和 hash 校验的产物。回滚只使用上一份 hash 仍匹配的归档。
3. 提交后无法确认的投递或远程任务进入 `unknown`，不自动重试、重复推理或重复投递。
4. 取消后无法确认远程服务已经停止时，保留服务 fence；确认空闲前不释放同一服务实例。
5. 用户明确发起恢复时复用原作业或 Asset 身份，而不是静默重新生成内容。

## 结果

失败恢复优先保证不重复执行，而不是追求表面可用性。普通“安装到已有 Harness”模式不包含独立协调器，因此不承诺项目受管升级和自动回滚。
