# Code of Conduct

[简体中文](CODE_OF_CONDUCT.md) | English

We aim to maintain a welcoming, professional and collaborative open-source community. Participants should:

- Respect differences in experience, identity, opinions and technical choices.
- Use constructive, clear language relevant to the issue.
- Accept evidence-based feedback and focus on code and its effects rather than individuals.
- Protect user privacy: do not disclose credentials, user IDs, platform tokens, logs or local paths.
- Follow the private reporting process in the [security policy](SECURITY.en.md) for security issues.

Unacceptable behavior includes harassment, discrimination, threats, personal attacks, malicious disclosure of private information or credentials, disruption of discussions, and interference with the normal operation of the project or platforms.

Report conduct concerns privately to the maintainers or through GitHub private vulnerability reporting. Maintainers will investigate while protecting participants' privacy and may issue warnings, remove content, restrict participation or revoke contribution access. Good-faith reports will not result in retaliation.
